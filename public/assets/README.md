# Browser art exports

These lightweight WebP files are derived from the owned iPhone art in
`ios/WobbleStack/Assets/WobbleStack/Resources/WobbleStack/Art/`.

The browser build ships cropped transparent sprites instead of loading the
original chroma-key sheets at runtime.

The `music/` tracks were supplied by the repository owner for Wobble Stack.
Public exports are loudness-normalized, metadata-free MP3 files; the source
masters are not committed.
